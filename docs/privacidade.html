Política de Privacidade

Aplicativo "Rumo a Vice City" · vigente desde 22 de setembro de 2026

Resumo

Este aplicativo é de uso pessoal do próprio autor. Ele existe para publicar vídeos nas contas de YouTube e Instagram que pertencem ao autor. Não há cadastro, não há usuários além do autor e não coletamos dados de terceiros.

Quem é o responsável

Diego Henrique Moraes — contato: gta6diegomoraes@gmail.com.

Que dados o aplicativo acessa

Ao ser autorizado pelo próprio autor, o aplicativo recebe um token de acesso do Google e da Meta que permite:

  • enviar vídeos e definir título, descrição, tags, miniatura e legenda no canal do YouTube do autor;
  • criar e publicar Reels e Stories na conta profissional do Instagram do autor;
  • ler estatísticas públicas e relatórios do próprio canal, para medir desempenho.

O aplicativo não lê, não coleta e não armazena dados de espectadores, seguidores ou de qualquer outra pessoa.

Onde os dados ficam

Os tokens de acesso ficam guardados como secrets criptografados no repositório do GitHub que executa o programa, e nunca são gravados em código, em log ou em arquivo do repositório. Nenhum dado é vendido, compartilhado ou transferido a terceiros.

Uso de dados da API do YouTube

Este aplicativo usa os Serviços de API do YouTube. Ao autorizá-lo, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google. O autor pode revogar o acesso do aplicativo a qualquer momento em myaccount.google.com/permissions.

Retenção e exclusão

Os tokens são mantidos enquanto o projeto estiver em operação e são apagados quando o acesso é revogado. Para pedir a exclusão de qualquer dado, escreva para o e-mail de contato acima.

Alterações

Mudanças nesta política são publicadas nesta mesma página, com a data de vigência atualizada no topo.
