As imagens e os vídeos são material de divulgação publicado pela própria Rockstar Games (trailers e galeria oficial de rockstargames.com/VI), usados conforme a política da Rockstar para publicação de material protegido por direitos autorais. Todo vídeo leva o crédito "Material oficial © Rockstar Games". Clipes de gameplay de terceiros só entram com licença Creative Commons BY, com crédito ao canal de origem.

Este site e o canal não têm vínculo com a Rockstar Games nem com a Take-Two Interactive.

Sobre este aplicativo

O canal é publicado por um programa próprio, de código aberto, que usa a YouTube Data API e a Instagram Graph API para enviar os vídeos às contas do próprio autor. O código está em github.com/diegohenriquemoraes-eng/gta6-canais.
